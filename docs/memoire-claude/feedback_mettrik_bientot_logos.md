Yann, 9 sept 2026 : dans un bloc de sté non encore créé (« Bientôt »), ne jamais écrire « Disponible dans les sept prochains jours » ni aucun délai chiffré : toujours « Disponible bientôt » (block-coming-soon.tsx). Les logos doivent venir d une base officielle (Wikipédia / Wikimedia Commons), script scripts/fetch-logo-wikipedia.py TICKER "Titre Wikipedia" : le fournisseur par domaine/ticker (Clearbit, parqet) a servi le logo d une autre sté (AXS) pour SpaceX.

**Why:** un délai chiffré non tenu décrédibilise ; un logo faux sur une fiche est une faute visible immédiatement par l investisseur.
**How to apply:** aucune mention de délai dans les placeholders ; pour tout logo manquant ou douteux, passer par Wikipédia (infobox) et vérifier visuellement (Read du PNG) avant commit. Voir [[reference-mettrik-logotheque]].
